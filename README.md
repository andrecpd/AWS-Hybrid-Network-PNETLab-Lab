# AWS-Hybrid-Network-PNETLab-Lab
This project simulates a real-world hybrid enterprise network integrating an AWS cloud environment with an on-premises branch running in PNETLab.

The architecture includes AWS networking services, Active Directory, Cisco ISE, Site-to-Site VPN connectivity, SD-WAN, dual ISP links, enterprise firewall, routing, switching, and client devices.

The lab is designed for hands-on practice with hybrid cloud networking, network security, redundancy, troubleshooting, authentication, and enterprise infrastructure.

The project will also be managed using Agile practices with Scrum, Kanban, Epics, User Stories, Tasks, and Sprints.
