# AWS Cost Governance Evidence

## Data da validação
18/09/2026

## Objetivo
Validar os controles de custo do laboratório AWS antes de avançar para a criação dos demais recursos de infraestrutura.

## Evidências registradas

- AWS Billing Dashboard revisado
- AWS Budget criado
- Alertas de custo configurados
- Limite financeiro do laboratório definido

## Resultado
A governança de custos do laboratório foi configurada para reduzir o risco de consumo inesperado dos créditos AWS e permitir acompanhamento do gasto durante a execução do projeto.
